# To-Do App

This is a simple yet functional **To-Do App** built with vanilla JavaScript. The app allows users to manage tasks effectively by adding, deleting, and marking them as complete.

## Features
- Add new tasks to the list
- Delete tasks with a single click
- Mark tasks as completed
- Interactive and responsive user interface
- Data persistence using localStorage (if applicable)

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)

## Usage
Type a task in the input field and press the "Add" button to add it to the list.
Click on a task to mark it as completed.
Use the delete button to remove a task from the list.
